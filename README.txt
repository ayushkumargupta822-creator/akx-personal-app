AKX — Personal OS

This is the AKX all-in-one personal workspace. The app name and default cream + gold + black appearance are retained.

Current modules include Home, Chess, Ludo, Calculator, Calendar, Study, Books, Tasks, Routine, Notes, Finance, Goals, Stats, Focus Room, Life Timeline, Memory Journal, Personalization, AKX AI prompt studio, and About.

New local features include a focus timer, basic XP and activity streak display, dashboard widget visibility controls, profile display name, global search across saved records, journal entries, timeline view, and JSON backup/restore.

Storage and privacy:
- Most records are stored locally in this browser using localStorage.
- Book files are stored separately in browser IndexedDB.
- JSON backup covers AKX record data but does not include PDF/document files stored in Books.
- This version does not provide account login, cloud sync, or encrypted cloud storage.
- Do not store passwords or highly sensitive information in the app.
- Keep exported backup files private.

To update: wait for GitHub Pages deployment, then close and reopen the installed PWA or refresh the website. If the installed copy remains stale, clear the site's cached data only after exporting a backup.
