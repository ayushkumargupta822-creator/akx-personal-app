AKX PERSONAL OS — VERSION 2
Features: AMOLED dashboard, responsive desktop sidebar/mobile bottom navigation, Study Hub, tasks, daily routine, notes, expense tracker, goals with progress sliders, weekly study bars, analytics and JSON data export. Offline app-shell cache updated to v2.

UPDATE YOUR GITHUB PAGES APP:
1. Open repository ayushkumargupta822-creator/akx-personal-app.
2. Upload and replace index.html, manifest.webmanifest, sw.js and icon.svg at the repository root.
3. Commit changes to main. Wait for GitHub Pages deployment.
4. Open the site and refresh. Close/reopen the installed AKX app if needed.

Data is saved locally in this browser only. It is not encrypted and does not sync between devices. Clearing site data can erase it. Do not store passwords or sensitive information. This is an installable PWA, not a native APK.
