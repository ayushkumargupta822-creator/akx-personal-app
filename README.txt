AKX — Modern Aurora Edition

Files: index.html, ludo.js, manifest.webmanifest, sw.js, icon.svg

To update GitHub Pages: upload/replace these four files in the repository root, commit changes, and wait for Pages deployment. Open the site in Chrome and refresh. The service worker cache version is updated to force the new theme.

Data is stored locally in this browser. Export a JSON backup from Settings before changing devices or clearing browser data. This app does not provide cloud sync or encrypted storage.
